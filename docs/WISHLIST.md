# Wishlist

Wishlist không phải backlog phải làm hết.

Chỉ promote một ý tưởng thành roadmap khi project hiện tại tạo nhu cầu thật.

## Community website

Một website tối giản có thể aggregate project và task sau này.

Chỉ làm khi GitHub navigation bắt đầu không đủ.

## Made in Vietnam project index

Danh sách project open-source Việt Nam đang thật sự welcome contributor.

Chỉ làm khi đã có nhiều hơn một vài project cần được kết nối.

## Recognition

Ghi nhận code, docs, translation, design, review và mentoring.

Không dùng leaderboard cạnh tranh.

## Organic contributor pilot

Nếu bắt đầu có contributor tự nhiên, có thể thử cải thiện onboarding cho một nhóm nhỏ.

Không đặt mục tiêu tuyển người chỉ để tăng số member.

## Open Source Quest

Học open-source bằng các quest nhỏ dẫn tới contribution thật.

```text
First Commit
↓
First Branch
↓
First Pull Request
↓
First Review
↓
First Real Project Contribution
```

## Every Concept in Plain Vietnamese

Mở rộng mô hình `Plain Vietnamese` ra ngoài IT khi content/review model đã chứng minh scale được.

## Vietnam Missions

Cùng hoàn thành một public-good project có phạm vi rõ.

## Contributor Passport

Profile tổng hợp contribution thật qua nhiều project.

## Maintainer Match

Kết nối contributor với project đang cần đúng skill.

## Monetization

Để sau validation.

Có thể xem xét sponsorship, sponsored public-good missions, hiring/job board hoặc corporate open-source program.

Core learning và contribution flow nên tiếp tục miễn phí.
