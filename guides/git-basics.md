# Git basics

Git là hệ thống quản lý phiên bản phân tán.

Nó giúp bạn lưu lịch sử thay đổi và làm việc với nhiều phiên bản của code.

## Git không phải GitHub

Git là công cụ quản lý version.

GitHub là một dịch vụ hosting repository Git và cung cấp thêm Issue, Pull Request, review và automation.

## Ba khái niệm đầu tiên

### Repository

Nơi chứa project và lịch sử Git của nó.

### Commit

Một mốc lưu lại một tập thay đổi.

### Branch

Một dòng phát triển độc lập để bạn thay đổi mà chưa tác động trực tiếp vào branch chính.
