# Tạo Pull Request đầu tiên

Mục tiêu của guide này là giúp bạn hoàn thành một contribution nhỏ.

Không cần học hết Git trước.

## 1. Chọn task

Tìm issue có label:

- `5-min`
- `first-pr`
- `no-setup` nếu bạn chưa muốn cài project

Đọc phần `Done when` trước khi claim.

## 2. Claim

Nếu issue chưa có người làm, comment:

```text
claim
```

Maintainer có thể xác nhận task cho bạn.

## 3. Thực hiện thay đổi

Làm đúng phần issue yêu cầu.

Không sửa thêm những phần không liên quan.

## 4. Tạo Pull Request

Viết title mô tả thay đổi.

Trong description, link tới issue và nói ngắn gọn bạn đã sửa gì.

## 5. Nhận review

Reviewer có thể approve hoặc yêu cầu sửa.

Yêu cầu sửa không có nghĩa contribution của bạn thất bại. Review là một phần bình thường của open-source.

## 6. Merge

Khi PR đạt acceptance criteria, maintainer merge nó.

Bạn vừa hoàn thành một open-source contribution.

Tiếp theo, bạn có thể chọn task khác hoặc review một thay đổi nhỏ.
