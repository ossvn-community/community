# Open-source là gì?

Open-source software là phần mềm có source code được cung cấp theo license cho phép người khác xem, dùng, sửa và phân phối theo các điều kiện của license đó.

`Public source code` không tự động có nghĩa là open-source.

## Tại sao có license?

License nói rõ bạn được phép làm gì với code.

Các license khác nhau có điều kiện khác nhau. Luôn đọc license của project trước khi dùng hoặc phân phối lại.

## Contribution là gì?

Contribution không chỉ là viết code.

Bạn có thể:

- Sửa docs.
- Report bug tốt.
- Viết test.
- Dịch nội dung.
- Review Pull Request.
- Thiết kế.
- Hỗ trợ người mới.
