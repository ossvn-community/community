# Start here

Bạn không cần đọc toàn bộ Organization và không cần join group trước.

Chọn đúng việc bạn muốn làm.

## Tôi chỉ muốn xem project

Bắt đầu với **IT in Plain Vietnamese**:

https://github.com/ossvn-community/it-in-plain-vietnamese

Bạn có thể chỉ đọc và sử dụng nội dung. Contribution là tùy chọn.

## Tôi chưa từng contribution open-source

1. Đọc [Open-source là gì?](guides/open-source.md).
2. Đọc [Git basics](guides/git-basics.md) nếu cần.
3. Mở Issues của project bạn muốn giúp.
4. Chọn một issue nhỏ hoặc sửa một lỗi rõ ràng.
5. Tạo Pull Request.
6. Nhận review và sửa nếu cần.

Mục tiêu đầu tiên chỉ là hoàn thành một contribution nhỏ.

## Tôi đã biết Git và GitHub

Đi thẳng tới repository bạn quan tâm.

Issue, test và review requirement phải nằm trong chính repository đó.

## Tôi có project open-source

OSSVN chưa ưu tiên xây project index ở giai đoạn này.

Cứ build project thật tốt trước. Project index và maintainer matching chỉ được mở khi có đủ nhu cầu thật.

## Tôi muốn giúp OSSVN lâu dài

Hãy bắt đầu bằng một contribution cụ thể.

Role reviewer hoặc maintainer được trao dựa trên contribution và mức độ tin cậy, không dựa riêng vào chức danh công việc.
